Fog Harbour
About
A simple interactive UE5 environment. A toxic fog spreads through the harbour, and the player must collect planks to escape!

Requirements:
Unreal Engine 5
Windows

How to run:
Download this repository from GitHub
Open the .uproject file in Unreal Engine 5
Open the main Level
Click Play to start Game

Controls
WASD: Move
F: Pick up planks
P: Pause Game
Esc: Exit Game

Gameplay:
Collect all the planks around the Harbour. Once you have collected them all, head to the shore to complete the game
